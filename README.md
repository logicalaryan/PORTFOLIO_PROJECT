## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Smooth scrolling navigation
- Hero section with social links
- Skills showcase with technology icons
- “Why I code” testimonial section
- Working contact form using Formspree

## 🧰 Tech Stack

- **HTML5**
- **CSS3**

## ▶️ Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/logicalaryan/PORTFOLIO_PROJECT.git
   ```
2. Open the project folder.
3. Launch `index.html` in your browser.

> Tip: Use VS Code Live Server for auto-refresh during edits.

## 🛠 Customize This Portfolio

<details>
  <summary><strong>Update personal information</strong></summary>

- Edit name, bio, and section text in `index.html`
- Replace social/contact links in the navbar and contact section

</details>

<details>
  <summary><strong>Change theme/colors</strong></summary>

- Modify CSS variables at the top of `styles.css`:
  - `--text-color`
  - `--link-color`
  - `--background-color`

</details>

<details>
  <summary><strong>Replace profile image and skill logos</strong></summary>

- Add your new files in `images/`
- Update matching `src` paths in `index.html`

</details>

<details>
  <summary><strong>Connect your own contact form endpoint</strong></summary>

- Replace the Formspree endpoint in the form `action` attribute inside `index.html`

</details>
